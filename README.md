# David Gutshall | Cursor Enterprise Sales Operating System

A polished, interactive single-page business plan web app for a strategic Cursor enterprise sales role focused on life sciences and pharma.

## Stack

- React
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide React
- Vite

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
